# DEMO STANDARDS — REPLACE WITH ORGANIZATION STANDARDS

Version: 1.0

## OCP-001 — Readiness Probes

Category: Platform
Technology: OpenShift

Production workloads must define readiness probes so traffic is routed only to containers that are ready to serve requests.

## OCP-002 — Liveness Probes

Category: Platform
Technology: OpenShift

Production workloads must define liveness probes so unhealthy containers can be restarted by the platform.

## OCP-003 — Resource Requests and Limits

Category: Platform
Technology: OpenShift

CPU and memory requests and limits must be configured for production workloads.
